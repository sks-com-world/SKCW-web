What is a computer?

What is CPU?

What is an operating system?
It manages hardware and software like Windows or Linux.
What is HTML?
HTML is used to create webpages.
What is CSS?
CSS is used to style webpages.
What is JavaScript?
JavaScript adds functionality to websites.
What is a browser?
A browser is used to open websites like Chrome or Firefox.
What is internet?
Internet is a global network connecting millions of devices.
